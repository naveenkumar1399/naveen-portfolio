This slot is ready. Import a SCORM 1.2 package to replace this placeholder and run the course in the player.

Option A - Import with the script (recommended)

Keep the package as a zip, then run:

python3 tools/import-scorm.py path/to/package.zip course-slug

Option B - Import manually

  1. Unzip the package into assets/scorm/course-slug/
  2. In assets/scorm/courses.json, set launch to the launch file path (from imsmanifest.xml).
  3. Set available to true and refresh this page.

The package runs fully client-side with a SCORM 1.2 run-time, so it works on static hosting with no LMS server.
